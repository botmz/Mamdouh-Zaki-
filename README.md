# MZ Telegram Automation — ناقل قنوات تيليجرام الذكي 🚀

نظام أتمتة متكامل واحترافي مصمم بالكامل باللغة العربية لنقل الرسائل والوسائط بين قنوات تيليجرام مع تصفية الروابط الذكية، عرض وتحديث أسعار الذهب والبيتكوين المباشرة، إدارة الرسائل الثابتة والمثبتة، ومنع تكرار الرسائل بنظام قيود صارم، مع لوحة تحكم ويب إدارية حديثة تعمل على مدار الساعة 24/7.

---

## 🌟 المزايا الرئيسية للمشروع

### 1. إدارة قنوات المصدر (Source Channels)
- إضافة وتعديل وحذف قنوات المصدر بالمعرف (`@username`) أو الرابط أو المعرف الرقمي (`-100...`).
- تفعيل القنوات أو إيقافها مؤقتًا بضغطة زر.
- ربط كل قناة مصدر بقنوات واجهة محددة أو بجميع الوجهات.
- فحص نوع القناة (عامة / خاصة) وتشخيص متطلبات الوصول والصلاحيات بدقة.
- منع إضافة نفس القناة مرتين نهائيًا عبر قيود فريدة.

### 2. إدارة قنوات الواجهات والوجهات (Destination Channels)
- إدارة قنوات الاستقبال بالكامل من لوحة التحكم دون تعديل أي ملفات كود.
- أداة اختبار صلاحيات البوت: تتحقق هل البوت مشرف (Administrator) وهل يملك صلاحية نشر الرسائل (`can_post_messages`).
- زر تجربة إرسال رسالة اختبارية والتأكد من نجاح النشر.
- ترتيب القنوات وأولويات الإرسال.

### 3. محرك تصفية الروابط ونقل الوسائط
- **حذف الروابط فقط مع الاحتفاظ بالنص الأصلي كاملاً:** لا يتم حذف الرسالة لمجرد احتوائها على رابط!
- معالجة الروابط المنسقة (Markdown Hyperlinks مثل `[النص](الرابط)`) بالحفاظ على النص وحذف الرابط.
- إعداد مستقل لمعالجة الروابط داخل نصوص الصور والفيديوهات والملفات (Captions) دون حذف الملفات الأصلية.
- الحفاظ على الوسائط الأصلية وجودتها وترتيبها.
- عدم إضافة علامة «تمت إعادة التوجيه من» أو روابط المصدر.
- عدم إضافة ترجمة تلقائية (الاحتفاظ بالنص كما هو بعد التصفية).

### 4. الأسعار المباشرة للذهب والبيتكوين (Live Prices Ticker)
- **سعر الذهب الفوري (XAU/USD):** بالدولار لكل أونصة تروي من أسواق المعادن و Yahoo Finance Front Spot.
- **سعر البيتكوين الفوري (BTC/USD):** لحظي ومباشر من واجهة Binance Live و CoinGecko.
- **مؤشرات الاتجاه الملونة:**
  - 🟢 ▲ صاعد (إذا ارتفع السعر عن آخر سعر مسجل)
  - 🔴 ▼ هابط (إذا انخفض السعر عن آخر سعر مسجل)
  - ⚪ ▬ محايد (إذا تساوى السعر)
- **تحديث الرسالة نفسها دون تكرار:** يقوم النظام بتعديل نص الرسالة الموجودة (`editMessageText`) عبر حفظ `message_id` لكل قناة واجهة، لمنع إغراق القناة برسائل مكررة كل دقيقة!
- زر «تحديث الآن» الفوري، مع إمكانية إيقاف أو تخصيص فترة التحديث.

### 5. الرسالة الثابتة والمثبتة (Pinned / Static Message)
- محرر مرئي للرسالة الثابتة مع دعم التنسيقات والروابط الخاصة بك.
- معاينة حية لشكل الرسالة على تيليجرام.
- إمكانية تثبيت الرسالة تلقائياً داخل القناة (`pinChatMessage`).
- تحديث الرسالة المثبتة السابقة عند تعديلها بدلاً من إعادة نشرها.
- إرسال اختياري تلقائي عند بدء تشغيل النظام أو عند إضافة قناة واجهة جديدة.

### 6. منع تكرار الرسائل بنظام القيود الصارمة (Deduplication Ledger)
- جدول مخصص في قاعدة البيانات مع قيد فريد صارم: `UNIQUE(source_channel_id, source_message_id, destination_channel_id)`.
- فحص إلزامي قبل كل إرسال؛ لن تُعاد الرسالة إطلاقاً عند انقطاع الإنترنت أو إعادة تشغيل الخادم.
- سجل كامل بحالة كل محاولة (`success` / `failed` / `pending`) مع زر لإعادة محاولة الرسائل الفاشلة.

### 7. الأمان وتسجيل الدخول
- لوحة تحكم محمية بنظام تشفير كلمات المرور Scrypt / PBKDF2 المعتمد.
- جلسات آمنة بتوكنات مشفرة 256-bit.
- إمكانية تغيير كلمة مرور المشرف واسم المستخدم من لوحة التحكم.
- إخفاء الرموز الحساسة ومفاتيح API في الواجهة.

## 📋 المتطلبات وقيم الإعداد المطلوبة منك

يجب تجهيز المتغيرات التالية ووضعها في ملف `.env`:

| المتغير | الوصف | المصدر |
| :--- | :--- | :--- |
| `TELEGRAM_BOT_TOKEN` | رمز بوت تيليجرام للنشر في القنوات | احصل عليه عبر محادثة [@BotFather](https://t.me/BotFather) |
| `JWT_SECRET` | مفتاح تشفير عشوائي لتأمين الجلسات | سلسلة نصوص عشوائية طويلة من اختيارك |
| `TELEGRAM_API_ID` | معرّف التطبيق لحساب تيليجرام (اختياري للقنوات الخاصة) | من [my.telegram.org](https://my.telegram.org) |
| `TELEGRAM_API_HASH` | المفتاح السري لتطبيق تيليجرام (اختياري للقنوات الخاصة) | من [my.telegram.org](https://my.telegram.org) |
| `GOLD_API_KEY` | مفتاح واجهة أسعار الذهب (اختياري) | اختياري (النظام يتضمن مصدراً مباشراً مجانياً مدمجاً) |

## 🛠️ خطوات التشغيل محليًا (Local Setup)

### 1. استنساخ المشروع وتثبيت الاعتماديات
```bash
# تثبيت حزم الواجهة وخادم Node.js
npm install

# تثبيت حزم بايثون إذا رغبت بتشغيل سكريبتات بايثون المستقلة
pip install -r requirements.txt
```

### 2. إعداد ملف البيئة
```bash
cp .env.example .env
# افتح ملف .env وضع فيه TELEGRAM_BOT_TOKEN الخاص بك
```

### 3. تشغيل خادم التطوير
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

بيانات الدخول الافتراضية للمدير:
- **اسم المستخدم:** `admin`
- **كلمة المرور:** `admin1234`
*(يمكنك تغيير كلمة المرور فوراً من قسم الإعدادات داخل لوحة التحكم).*

## 🌐 دليل النشر والتشغيل المستمر 24/7 على سيرفر VPS (Ubuntu / Debian)

لضمان عمل النظام على مدار الساعة دون توقف عند إغلاق جهازك، يوصى بنشره على سيرفر سحابي خاص (VPS مثل Hetzner أو DigitalOcean أو Oracle Cloud مجاناً أو Contabo).

### الخيار الأول: عبر خدمة Systemd (موصى به جداً)

1. **انسخ المشروع إلى السيرفر:**
   ```bash
   sudo mkdir -p /opt/mz-telegram-automation
   sudo cp -r . /opt/mz-telegram-automation
   cd /opt/mz-telegram-automation
   ```

2. **بناء المشروع وتثبيت الحزم:**
   ```bash
   npm install
   npm run build
   ```

3. **تفعيل وتشغيل خدمة النظام:**
   ```bash
   sudo cp systemd/mz-telegram.service /etc/systemd/system/
   sudo systemctl daemon-reload
   sudo systemctl enable mz-telegram
   sudo systemctl start mz-telegram
   ```

4. **فحص حالة التشغيل:**
   ```bash
   sudo systemctl status mz-telegram
   ```

### الخيار الثاني: عبر Docker Compose

```bash
docker compose up -d --build
```
سيعمل النظام في حاوية معزولة ويعيد التشغيل تلقائياً إذا حدث أي خطأ (`restart: always`).

## ⚠️ تنبيه بخصوص الاستضافات المجانية (Replit Free / Glitch / Render Free)
الاستضافات المجانية تقوم بإيقاف خادم التطبيق وتنويمه (Sleep / Spin down) بعد 15 دقيقة من عدم وجود زوار، مما يوقف نقل الرسائل وتحديث الأسعار التلقائي. لذلك:
- للتشغيل الحقيقي المستمر، استخدم سيرفر VPS أو خدمة استضافة تدعم Background Workers الدائمة.
- يدعم النظام نقطة فحص الصحة `/api/health` للربط مع أدوات المراقبة الخارجية (مثل UptimeRobot) لإرسال تنبيه في حال توقف السيرفر.
